# Database Schema Documentation

## Entity Relationship Diagram & Tables Summary

The PostgreSQL database schema consists of 22 normalized relational tables:

1. `users`: Core identity credentials, email, password hash (bcrypt), role, active status.
2. `refresh_tokens`: Hashed refresh tokens (`token_hash`), expiration dates, revocation timestamps.
3. `email_verification_tokens`: Verification token hashes.
4. `password_reset_tokens`: Password reset token hashes.
5. `district_admin_profiles`: Maps District Admin user to `district_code`.
6. `officer_profiles`: Maps Grievance Officer to `officer_id`, `district_code`, `department_id`, availability, active workload count.
7. `districts`: All 55 Madhya Pradesh districts (Code, English Name, Hindi Name).
8. `departments`: Public departments (PWD, PHE, MPPKVVCL, Nagar Nigam, Transport, Revenue, IT/MPOnline, Sanitation).
9. `categories`: Complaint categories with default SLA hours.
10. `category_department_mappings`: Authoritative category to department mapping.
11. `sla_rules`: Priority multipliers (HIGH: 0.5x, MEDIUM: 1.0x, LOW: 1.5x).
12. `complaints`: Primary complaint records (`complaint_no`, `tracking_code`, `citizen_id`, `is_anonymous`, `contact_email`, `contact_mobile`, `subject`, `description`, `district_code`, `location_address`, `category_id`, `department_id`, `priority`, `status`, `assigned_officer_id`, `sla_deadline`, `is_overdue`, `resolution_summary`, `resolved_at`, `closed_at`).
13. `anonymous_access_sessions`: Token hashes for anonymous complaint sessions.
14. `complaint_attachments`: Uploaded file attachments (filename, path, file type, file size).
15. `complaint_status_history`: Immutable chronological audit timeline events.
16. `complaint_messages`: Structured communication messages thread.
17. `notifications`: In-app notification alerts for users.
18. `feedback`: Rating (1-5), comments, satisfaction flag.
19. `escalations`: SLA delay escalation logs.
20. `reopen_requests`: Justification for reopening resolved/closed complaints (`status`: PENDING, APPROVED, REJECTED).
21. `ai_recommendations`: Category, department, priority recommendations generated by AI/Rule engine.
22. `ai_insights`: Aggregated district executive summaries generated by AI.
